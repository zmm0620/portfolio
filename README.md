# 朱漫漫的视觉设计作品集

个人视觉设计作品集网站，展示品牌设计、营销视觉、手册与印刷、内容视觉、界面与创意。

当前版本包含五个作品分类、17 个项目和 147 张完整作品及页面图，配套网页缩略图。页面文字采用现代无衬线字体。

## 本地预览

解压或克隆本仓库后，可直接在浏览器打开 `index.html`。

也可以使用 Node.js 启动本地预览，无需安装依赖：

```sh
npm run dev
```

随后打开 http://127.0.0.1:4174/ 。

## 文件结构

- `index.html`：网站入口与公共导航。
- `style.css`：字体、排版与响应式样式。
- `app.js`：页面渲染、分类导航、作品详情与图片查看。
- `portfolio-data.js`：项目文案、分类和图片清单。
- `assets/portfolio/`：作品图片及缩略图。
- `favicon.svg`：网站图标。
- `server.mjs`：本地预览服务器。

## 页面

- `#/`：作品首页。
- `#/category/brand`：品牌设计分类；其他分类为 `marketing`、`editorial`、`content`、`digital`。
- `#/project/kaihui-identity`：项目详情示例。
- `#/about`：个人介绍与工作经历。

网站为纯静态 HTML、CSS 和 JavaScript，可以部署至支持静态网站的托管服务。哈希路由无需服务端重写配置。

## 内容维护

在 `portfolio-data.js` 中修改项目标题、说明和图片路径，在 `style.css` 中调整视觉样式。作品原图中的文字属于设计素材，页面字体样式不会改变图片内容。

运行基本检查：

```sh
npm run check
```

本仓库内容用于个人作品展示，未附加开源授权。
